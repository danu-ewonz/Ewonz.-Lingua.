HIRAGANA SPECIAL PRACTICE
SOKUON (っ)
Small pause → double consonant
がっこう = gakkou (school)
さっか = sakka (author)
CHOON (ー)
Long vowel sound
おかあさん = okaasan
おおきい = ookii
DAKUTEN (゛)
K → G, S → Z, T → D, H → B
か → が
さ → ざ
た → だ
は → ば
HANDAKUTEN (゜)
H → P only
は → ぱ
ひ → ぴ
ふ → ぷ
へ → ぺ
ほ → ぽ
EXAM TIP
One small symbol changes meaning completely
かこ ≠ かっこ
コーヒー ≠ コヒ
は → ば → ぱ
