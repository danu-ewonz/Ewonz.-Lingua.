HIRAGANA CHOON (長音)
Meaning
Long vowel sound in Hiragana
Basic Idea
Sound is stretched (not using ー)
Example (あ)
おかあさん (okaasan) = Mother
Example (い)
おじいさん (ojiisan) = Grandfather
Example (う)
すうがく (suugaku) = Math
Example (え)
ねえ (nee) = Hey / Sister call
Example (お)
おおきい (ookii) = Big
Exam Tip
Hiragana long vowel = repeat vowel

あ → ああ (aa)
い → いい (ii)
う → うう (uu)
え → えい / ええ
お → おう / おお
